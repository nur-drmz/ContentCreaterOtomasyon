# Project Journal

This directory preserves cross-session context for the local AI Content
Intelligence & Production Platform.

## Resume a new session

Read these files in order:

1. [`2026-07-26-preflight-session.md`](2026-07-26-preflight-session.md) —
   latest verified worker/preflight implementation and continuation point.
2. [`2026-07-26-session.md`](2026-07-26-session.md) — earlier decisions, work completed,
   verified state and continuation point.
3. [`../pre-alpha-local/00-index.md`](../pre-alpha-local/00-index.md) — current
   Pre-Alpha source of truth.
4. [`prompts/2026-07-26-versioned-development-reporting-claude.md`](prompts/2026-07-26-versioned-development-reporting-claude.md)
   — latest prepared Claude implementation prompt.
5. [`prompts/2026-07-26-sequential-worker-preflight-claude.md`](prompts/2026-07-26-sequential-worker-preflight-claude.md)
   — historical implementation brief; its scope is now implemented locally.

## Journal policy

- Add a new dated session file rather than rewriting history.
- Record only verified results as completed.
- Keep Claude handoff claims separate from independently verified results.
- Update the continuation point before ending a development session.
- Raw exported chat transcripts, if added later, should go under
  `docs/project-journal/raw/` and must not contain secrets.
